# Test262 Conformance Status

This document tracks ECMAScript conformance progress against the [tc39/test262](https://github.com/tc39/test262) suite.
It is updated each time a significant batch of tests is run or a coverage area is fixed.

---

## How to read this document

- **Snapshots** are generated by `tests/test262/runner/test262_runner.js` and stored under `tests/test262/reports/`.
- **Aggregated numbers** below are computed from the latest snapshot per pattern (1,097 unique patterns as of last update).
- `failed_syntax` = test failed because the parser rejected valid code (or accepted invalid code).
- `failed_semantics` = test compiled but produced wrong runtime behaviour.
- **Timeouts** (default 10 s per test) often indicate infinite loops — treat them as high-priority regressions.

## Recommended Next Steps

Priority is ordered by **ROI** (tests recovered / implementation effort).

### Tier 1 — Critical / high ROI

#### 1. Timeouts in `built-ins/Array` (2,137 timeouts)
- Timeouts indicate infinite loops, not missing features — they are active regressions.
- Likely a single Array method is hanging (candidates: `sort`, `forEach`, `every`).
- **Action:** reproduce the smallest failing test locally, identify the looping method, fix.

#### 2. Timeouts in `built-ins/Object` (337 timeouts)
- Same class of problem — probably property descriptor iteration or prototype chain traversal.
- **Action:** isolate the hanging method in the Object snapshot and fix the loop condition.

#### 3. Crashes in `language/expressions` (`Command failed`)
- 9,473 failures; error is `Command failed` (process exits non-zero), not an assertion.
- Array sub-expressions are the first affected pattern.
- **Action:** run a single failing test manually with `protojs`, inspect the exit code / stderr.

---

### Tier 2 — Medium effort, high impact

#### 4. `built-ins/Promise` — 711 failures (47.9%)
- Root causes: `Symbol.species` not forwarded on Promise subclasses; `Promise.all` edge cases.
- Fixing `Symbol.species` on Promise likely recovers a large cluster of tests.
- **Action:** implement `Promise[Symbol.species]` and audit `Promise.all` / `Promise.race`.

#### 5. `built-ins/RegExp` — 1,772 failures (59.3%)
- `RegExpStringIteratorPrototype` is the first failing group — the iterator is not implemented.
- **Action:** implement `String.prototype.matchAll` + `%RegExpStringIterator%` prototype.

#### 6. `language/statements` — 138 syntax failures
- The parser is rejecting syntactically valid statement constructs.
- **Action:** collect the 138 `failed_syntax` paths, identify the common construct, fix the parser.
