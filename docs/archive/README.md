# Archive

This directory holds historical protoJS documents: dated plans, phase completion reports, status snapshots and development logs. They are kept for reference, are not maintained, and may not match the current code. Completion and "production ready" claims made in them are superseded: protoJS is not production ready. Current documentation is indexed in [docs/README.md](../README.md).
